실시간 미리보기

내 GitHub에 배포하기

여기서 배포하면, 만든 운영페이지가 인터넷에 올라가고 수강생에게 보낼 주소가 생깁니다. 처음에는 아래 1~2단계를 준비하고, 이후에는 같은 저장소에 다시 배포해 내용을 수정할 수 있습니다.

예시 공개 주소
https://내아이디.github.io/education-1023/
아래 예시의 ‘내아이디’와 ‘education-1023’은 본인의 GitHub 아이디·저장소 이름으로 바꿔 주세요.
1. 운영페이지를 담을 공개 저장소 만들기 처음 한 번

저장소(repository)는 운영페이지 파일을 보관하는 폴더라고 생각하시면 됩니다. 교육별로 새 저장소를 만들면 각각 다른 주소를 받을 수 있습니다.

GitHub 저장소 만들기 화면 열기 ↗
  1. GitHub에 본인 계정으로 로그인합니다. 계정이 없으면 먼저 가입해 주세요.
  2. Owner에서 본인 아이디를 선택합니다.
  3. Repository name에 영문·숫자·하이픈으로 이름을 적습니다.
    예: education-1023
  4. 공개 범위를 Public으로 선택합니다. 나머지는 기본값으로 두어도 됩니다.
  5. Create repository를 누릅니다.
  6. 완료된 화면의 주소를 복사해 아래 저장소 주소 칸에 붙여넣습니다.
    예: https://github.com/내아이디/education-1023
2. GitHub 토큰 발급하기 배포 권한 연결

토큰(token)은 이 도구가 내 저장소에 파일을 올릴 수 있게 하는 임시 열쇠입니다. GitHub 로그인 비밀번호를 입력하는 것이 아닙니다.

GitHub 토큰 발급 화면 열기 ↗
  1. Token name에 알아보기 쉬운 이름을 적습니다.
    예: 교육운영페이지 배포
  2. Expiration에서 사용할 기간을 선택합니다. 짧은 기간을 권장합니다. 만료 후에는 새 토큰을 발급하면 됩니다.
  3. Resource owner가 본인 아이디인지 확인합니다.
  4. Repository access → Only select repositories를 선택하고, 1단계에서 만든 저장소를 체크합니다.
  5. Permissions → Repository permissions에서 아래 권한을 추가합니다. 화면에 Add permissions 버튼이 보이면 눌러서 항목을 찾으세요.
권한 이름선택할 값필요한 이유
ContentsRead and write페이지 파일 올리기
PagesRead and write공개 주소 생성·배포 상태 확인
AdministrationRead and write처음 GitHub Pages를 켤 때 필요

이미 GitHub Pages가 켜져 있는 저장소라면 Administration 권한은 필요하지 않습니다. Metadata는 자동으로 포함됩니다.

  1. 맨 아래 Generate token을 누릅니다.
  2. 생성된 github_pat_... 값을 복사해 아래 GitHub 토큰 칸에 붙여넣습니다. 토큰은 생성 직후에만 전체 내용을 볼 수 있습니다.

토큰은 다른 사람에게 보내거나 페이지 내용에 적지 마세요. 이 도구는 토큰을 저장하지 않으므로, 다시 배포할 때 입력해야 합니다.

3. 아래에 붙여넣고 배포하기
  1. 아래 두 칸에 저장소 주소와 토큰을 붙여넣습니다.
  2. 교육 정보와 연결된 자료가 공개되어도 되는지 확인하고 인터넷 공개 동의에 체크합니다.
  3. 이 저장소에 배포하기를 누르고 완료 안내가 나올 때까지 기다립니다.
  4. 완료 후 표시되는 공개 주소를 복사해 수강생에게 보내면 됩니다.

이미 배포한 페이지를 수정할 때는 내용을 고친 뒤 같은 저장소 주소로 다시 배포하세요. 기존 페이지 교체 확인 창에서 확인을 누르면 같은 주소의 내용이 업데이트됩니다.

토큰은 GitHub API(api.github.com)에만 전송되며 파일·브라우저 저장소·제작 도구 서버에는 저장하지 않습니다. 창을 닫으면 입력칸에서 지워집니다.

같은 저장소에 다시 배포하면 기존 index.html이 교체됩니다. 다른 교육은 별도 저장소를 사용하세요.
