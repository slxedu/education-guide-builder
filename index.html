편집 중 입력값은 브라우저에서 처리됩니다. 배포 시 선택한 GitHub 저장소로 전송됩니다. 저장 파일은 다른 담당자와 공유할 수 있습니다. GitHub 배포 버튼으로 본인 저장소에 게시하거나 HTML 파일로 내려받을 수 있습니다.

실시간 미리보기

내 GitHub에 배포하기

본인 GitHub 계정의 공개 저장소에 운영페이지를 게시합니다.

  1. GitHub에서 새 공개 저장소 만들기 ↗
    운영페이지 전용 저장소를 만들어 주세요. README는 선택 사항입니다.
  2. Fine-grained 토큰 발급하기 ↗
    Repository access: 위 저장소만 선택
    Repository permissions: Contents와 Pages를 Read and write로 설정
    첫 배포에서 Pages 자동 설정까지 하려면 Administration도 Read and write로 추가
    이미 Pages가 켜진 저장소는 Administration 권한 불필요
    짧은 만료기간을 설정해 주세요.

토큰은 GitHub API(api.github.com)에만 전송되며 파일·브라우저 저장소·제작 도구 서버에는 저장하지 않습니다. 창을 닫으면 입력칸에서 지워집니다.

같은 저장소에 다시 배포하면 기존 index.html이 교체됩니다. 다른 교육은 별도 저장소를 사용하세요.
