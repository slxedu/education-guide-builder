# 솔트룩스 교육 운영페이지 만들기

1. 제작 도구에서 공개교육 또는 환급과정을 선택합니다.
2. 예시 내용을 실제 과정 정보로 바꿉니다.
3. 자료·계정·설문 링크와 시설 안내를 입력합니다. 시설 비밀번호 등은 게시 범위를 확인해 입력하세요.
4. PC·모바일 미리보기를 확인하고 HTML을 다운로드합니다.
5. 홈페이지 관리자 또는 GitHub Pages 저장소에 업로드합니다. GitHub Pages에서는 다운로드한 파일을 index.html로 이름을 바꿔 올리면 됩니다.

HTML에는 스타일과 로고가 포함됩니다. 글꼴은 인터넷 연결 시 불러오며 오프라인에서는 기본 글꼴로 표시됩니다.
입력 내용 저장은 JSON 파일을 내려받습니다. 다른 담당자는 이 파일을 불러와 이어서 편집할 수 있습니다.
입력값을 서버에 저장하거나 자동 배포하지 않습니다. 새로고침 전에 입력 내용 저장을 눌러 주세요.
