# 솔트룩스 교육 운영페이지 만들기

1. 제작 도구에서 공개교육 또는 환급과정을 선택합니다.
2. 예시 내용을 실제 과정 정보로 바꿉니다.
3. 자료·계정·설문 링크와 시설 안내를 입력합니다. 시설 비밀번호 등은 게시 범위를 확인해 입력하세요.
4. PC·모바일 미리보기를 확인하고 HTML을 다운로드합니다.
5. 홈페이지 관리자 또는 GitHub Pages 저장소에 업로드합니다. GitHub Pages에서는 다운로드한 파일을 index.html로 이름을 바꿔 올리면 됩니다.

HTML에는 스타일과 로고가 포함됩니다. 글꼴은 인터넷 연결 시 불러오며 오프라인에서는 기본 글꼴로 표시됩니다.
입력 내용 저장은 JSON 파일을 내려받습니다. 다른 담당자는 이 파일을 불러와 이어서 편집할 수 있습니다.
입력값을 서버에 저장하거나 자동 배포하지 않습니다. 새로고침 전에 입력 내용 저장을 눌러 주세요.

## 본인 GitHub 계정으로 바로 배포

1. GitHub에서 운영페이지 전용 **공개 저장소**를 만듭니다.
2. Fine-grained personal access token을 발급합니다. Repository access에서 해당 저장소만 선택하고 Contents와 Pages에 Read and write를 줍니다. Pages 최초 자동 설정에는 Administration 쓰기 권한도 필요합니다. 이미 Pages가 설정된 저장소는 Administration 권한이 필요하지 않습니다.
3. 제작 도구의 GitHub에 배포하기에서 저장소 주소와 토큰을 입력합니다.
4. 공개 동의를 확인하고 배포합니다. 완료 시 공개 주소가 표시됩니다.

토큰은 GitHub API에만 전송됩니다. 저장하거나 다운로드 파일에 포함하지 않습니다. 배포가 끝나거나 창을 닫으면 지웁니다. 같은 저장소 재배포 시 기존 index.html 교체 여부를 확인합니다. 다른 계정 소유 저장소와 비공개 저장소에는 배포하지 않습니다.

## 색상

하늘색, 그린, 오렌지, 네이비, 퍼플을 선택할 수 있으며 포인트 색상과 연한 배경색을 직접 지정할 수도 있습니다. 선택한 색상은 미리보기, 다운로드 HTML, GitHub 배포에 함께 반영됩니다.
